# Number Guessing Game

A Java Swing game where you guess a secret number within 5 chances.

## Requirements

- JDK 8 or newer

## How to Run

1. Download or clone this repository.
2. Open a terminal in the project folder and compile:

   ```bash
   javac NumberGuessingGame.java
   ```

3. Run the game:

   ```bash
   java NumberGuessingGame
   ```

4. Enter a lower and upper limit, click **START GAME**, then type your guesses and press Enter or click **SUBMIT GUESS**.
